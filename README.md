## 🔍 Project Overview
This project implements a **privacy-preserving phishing detection system** capable of analyzing **encrypted emails** without decrypting their content.  
It combines **machine learning**, **TF-IDF vectorization**, and **homomorphic encryption** to detect phishing attacks while keeping user data secure.  

**Key Goals:**
- Detect phishing attempts **without accessing plaintext**  
- Demonstrate **encrypted ML pipelines**  
- Serve as a **research & educational tool** for privacy-preserving email security
